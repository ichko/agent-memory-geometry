About this map

Each path is one real conversation session. Lines follow turn order. Separate sessions are never joined.

Projection is for exploration. Nearby points are not proof that a fact was stored or retrieved. Memory overlays use shared analysis embeddings, not native retrieval vectors.

Files opened manually stay in your browser tab and are not uploaded. This viewer makes no embedding API calls.
