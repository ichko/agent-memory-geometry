Memory Atlas data

The public demo contains conversation texts and questions from LongMemEval-small (cleaned), with sampled memory texts from the paper's evaluated systems.

Shared analysis embeddings use the public redis/langcache-embed-v3-small model. Model weights, original vectors, caches, generated answers, and private backend configurations are not distributed.

Credential-shaped examples and local paths are omitted from displayed text. Coordinates and cosine similarities are unchanged and were computed before this display-only redaction. The downloaded metadata records the number of affected points. Memory samples are not complete stores. Similarity is not verified provenance, factual coverage, or actual retrieval.
